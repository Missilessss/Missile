PERIODIC TABLE — CHEMISTRY LEARNING HUB

Cara menjalankan:
1. Ekstrak seluruh isi ZIP ke satu folder.
2. Buka index.html menggunakan browser modern.
3. Pastikan index.html, style.css, script.js, dan elements.js tetap berada dalam folder yang sama.

Fitur:
- Tabel periodik 118 unsur, pencarian, filter kategori, detail unsur, dan diagram kulit elektron.
- Unsur pilihan hari ini, partikel interaktif berisi fakta kimia, daftar favorit, dan pembanding dua unsur.
- Study notes: sifat periodik, prinsip Aufbau, larangan Pauli, aturan Hund, bilangan kuantum, kestabilan atom/ion, dan rumus cepat.
- Chemistry tools: pembagian elektron per kulit, konfigurasi elektron ion, pemeriksa bilangan kuantum, dan perkiraan kecenderungan kestabilan.

Catatan belajar:
Alat hitung ditujukan untuk konsep dasar. Konfigurasi elektron beberapa unsur memiliki pengecualian, dan aturan oktet/kecenderungan ion tidak berlaku mutlak untuk semua unsur. Periksa kembali dengan materi kelas atau buku pelajaran.

Website berjalan lokal di browser dan tidak memerlukan instalasi. Font dari Google Fonts dapat memerlukan koneksi internet; jika tidak tersedia, browser memakai font pengganti.


Fitur Isotopes: memuat daftar nuclide dari dataset all-isotopes saat internet tersedia. Dataset ini menyatakan sumber data NIST yang dikompilasi pada September 2023 dan berlisensi MIT (lihat https://github.com/sjf8203/all-isotopes). Jika offline, tersedia fallback untuk isotop umum pada sejumlah unsur. Efek dekoratif coquette menggunakan aksen pita dan bunga kecil.

Pembaruan mode isotop:
- Tekan tombol “Buka mode isotop” di bawah tabel periodik untuk menampilkan mode isotop. Mode ini tidak terbuka otomatis.
- Kotak unsur menampilkan jumlah isotop yang tersedia pada data yang dimuat.
- Klik unsur pada tabel untuk membuka kartu-kartu isotop yang tersusun dari kiri ke kanan lalu berlanjut ke baris berikutnya.
- Kartu menunjukkan nomor massa, massa isotop, jumlah proton, jumlah neutron, dan kelimpahan alami jika tersedia. Tekan “×” untuk menutup panel.
- Judul halaman diberi aksen pita, bunga, dan kilau dekoratif; judul utama tetap “Periodic Table”.

Finishing touches: the visible “A LITTLE NUCLEAR DISCOVERY / Isotopes” section has been removed from the page; isotope exploration remains available through the periodic-table isotope mode. A sparse chemistry-symbol particle layer drifts slowly behind the whole page and gently repels mouse/touch input. Electron dots orbit in the atom diagrams.

Pemeriksaan data dan batasan:
- Berisi 118 unsur; jumlah elektron per kulit pada data unsur diperiksa agar totalnya sama dengan nomor atom untuk atom netral.
- Massa atom pada tabel ditampilkan sebagai nilai ringkas untuk pembelajaran, bukan pengganti data presisi laboratorium. Konfigurasi elektron dan kecenderungan ion memiliki pengecualian yang disebutkan di halaman.
- Mode isotop memakai fallback ringkas untuk 28 unsur saat offline. Jika internet tersedia, website mencoba memuat dataset isotop pihak ketiga; kelengkapan dan pembaruan data mengikuti sumber tersebut. Jangan anggap data fallback sebagai daftar semua isotop yang diketahui.
- Referensi pembanding untuk massa atom dan isotop: NIST Atomic Weights and Isotopic Compositions, https://physics.nist.gov/cgi-bin/Compositions/stand_alone.pl?ascii=ascii
- Referensi penjelasan massa atom standar dan komposisi isotop: https://www.nist.gov/pml/atomic-weights-and-isotopic-compositions-column-descriptions
